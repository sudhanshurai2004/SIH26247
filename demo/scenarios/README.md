# Training-only demo scenarios

These JSON files are deterministic, frozen snapshots generated by the local
core. They contain no real doctrine, sensor signature, targeting, weapon, or
electronic-warfare data.

| File | Seed | Purpose | Environment / difficulty |
| --- | ---: | --- | --- |
| `01-scripted-clear-single.json` | `2624701` | Scripted single-target introduction | abstract flat / day / clear / 1 |
| `02-swarm-rural-day.json` | `2624702` | Six-member simulated swarm with two abstract distractors | rural / day / clear / 2 |
| `03-night-degraded-urban.json` | `2624703` | Higher-difficulty swarm and clutter session generated through the abstract night/rain sensor model | urban / night / rain / 3 |

`03` is called **degraded-sensor night** only in the synthetic training sense:
its `t_visible_ms` values were generated under the repository's rule-based
night/rain sensor factors. It is not a representation of a real sensor,
radar, electro-optical system, or EW effect.

Run `make demo-seed` only against the disposable demo SQLite database to create
ready sessions for these snapshots. The script refuses a non-empty database
unless `--reset` is explicit.
